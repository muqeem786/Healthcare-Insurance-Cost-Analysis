# Healthcare Insurance Cost Analysis

## Project Overview

This project presents an interactive Healthcare Insurance Cost Analysis Dashboard developed in Excel to analyze insurance charges, patient demographics, smoking habits, BMI categories, and regional healthcare costs. The dashboard helps identify factors that influence insurance expenses and supports data-driven decision-making in the healthcare insurance sector.

## Key Metrics

* Total Patients: 1338
* Average Charges: $13,270.42
* Smoker Percentage: 20.48%
* Maximum Claim Amount: $63,770.43

## Features

* Region-wise Insurance Cost Analysis
* BMI Category-wise Average Charges
* Smoker vs Non-Smoker Comparison
* Age Group-wise Cost Analysis
* Smoking Impact on Insurance Charges
* Regional Healthcare Cost Comparison
* Interactive Filters and Slicers
* Patient Demographics Analysis

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Analysis

## Key Insights

* Smokers incur significantly higher insurance charges than non-smokers.
* Healthcare costs increase with age.
* Obese patients have the highest average insurance charges among BMI categories.
* The southeast region records the highest total insurance charges.
* Smoking status and BMI are major factors influencing insurance costs.
